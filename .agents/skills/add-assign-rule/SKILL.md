# 배분 규칙 보강

## 언제 쓰는지

배분 엔진의 1순위 정확도가 목표에 못 미치거나, 공통 키워드가 업무 고유 키워드보다 높은 점수를 받아 잘못된 과가 1순위가 될 때 사용한다. 원본 배분기준표를 보존하면서 사용자가 고른 제외어·키워드·우선순위 변경만 사본에 반영해야 하는 작업에 적용한다.

## 순서

1. `AGENTS.md`, `PROGRESS.md`, `CONTEXT.md`를 읽고 배분기준표·조직도 26개 과·시험 40건·접수대장 520건과 현재 엔진의 점수 계산식을 확인한다.
2. 틀린 문항마다 일치 규칙, 과, 점수, 근거키워드를 비교해 원인별로 묶고, 각 원인에 `제외어 추가`, `키워드 추가`, `우선순위 변경` 중 가장 작은 수정안 하나를 제안한다.
3. 사용자가 고른 수정만 원본과 같은 행 구조의 `data/rules_보강.csv`에 반영한다. 원본 배분기준표는 수정하지 않으며, 변경할 과가 조직도 26개 과 안에 있는지 확인한다.
4. 같은 엔진으로 원본과 보강본을 각각 실행해 시험 40건과 접수대장 520건의 1순위 정확도를 비교하고, 기존 정답이 새 오답이 된 문항을 별도로 센다. 변경 행·열·전후 값을 확인해 선택하지 않은 셀이 달라지지 않았는지도 검사한다.
5. 바꾼 규칙, 전후 정확도, 새 오답 수와 남은 오답을 `PROGRESS.md`에 기록하고 결과표를 보고한다. 시험 1순위가 30/40 이상이고 새 오답이 0건인지 명시한다.

## 끝나는 조건

- `rules_보강.csv`의 행 수와 열 구조가 원본과 같다.
- 사용자가 선택한 규칙의 지정 셀만 달라졌다.
- 모든 배분 과가 조직도 26개 과 안에 있다.
- 시험 40건과 접수대장 520건의 변경 전·후 1순위 정확도가 계산됐다.
- 새로 틀린 문항이 0건이고 시험 1순위가 30/40 이상이다.
- 변경 규칙과 검증 결과가 `PROGRESS.md`에 기록됐다.

## 하지 말 것

- 원본 `data/배분기준표_소관키워드_304건.csv`, 조직도, 시험자료와 접수대장을 수정하지 않는다.
- 사용자가 선택하지 않은 제안이나 규칙을 사본에 넣지 않는다.
- 조직도에 없는 과를 새로 만들거나 후보로 허용하지 않는다.
- 시험 정답이나 특정 문항을 엔진 코드에 직접 써서 정확도를 올리지 않는다.
- 정확도만 보고 완료하지 않는다. 새 오답, 변경 셀, 행 수와 조직도 범위를 함께 확인한다.
